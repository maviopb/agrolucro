
# AgroLucro - Sistema de Gestão Financeira Rural

## Sobre o projeto

O **AgroLucro** é um sistema web de gestão financeira desenvolvido para auxiliar produtores rurais no controle de receitas, despesas e movimentações financeiras de suas propriedades.

O objetivo é oferecer uma plataforma simples, moderna e intuitiva, permitindo uma melhor organização das finanças e facilitando a tomada de decisões.

O projeto está sendo desenvolvido como parte dos estudos em Ciência da Computação, aplicando conhecimentos de HTML, CSS e JavaScript.

## Objetivo

Desenvolver uma aplicação web que permita:

- Registrar receitas e despesas.
- Consultar movimentações financeiras.
- Acompanhar o saldo da propriedade.
- Visualizar relatórios e gráficos.
- Organizar movimentações por categorias.
- Estabelecer metas financeiras.
- Facilitar o controle financeiro rural.

## Funcionalidades

### 1. Login e cadastro
- Tela de autenticação.
- Cadastro demonstrativo de usuários.
- Acesso ao painel principal.

### 2. Dashboard
- Exibição do saldo atual.
- Total de receitas.
- Total de despesas.
- Gráfico de resumo financeiro.
- Movimentações recentes.

### 3. Movimentações financeiras
- Cadastro de entradas e saídas.
- Descrição da movimentação.
- Seleção de categoria.
- Registro de valores e datas.
- Campo de observações.
- Edição e exclusão de registros.

### 4. Histórico financeiro
- Listagem de movimentações.
- Pesquisa por descrição ou categoria.
- Filtro por tipo de movimentação.
- Filtro por mês.
- Gerenciamento dos registros.

### 5. Relatórios
- Resumo de receitas e despesas.
- Cálculo do resultado financeiro.
- Listagem dos lançamentos.
- Exportação de dados em CSV.

### 6. Gráficos
- Comparação entre receitas e despesas.
- Despesas por categoria.
- Resultado financeiro mensal.

### 7. Visão geral
- Saldo acumulado.
- Quantidade de registros.
- Meta mensal de receitas.
- Barra de progresso financeiro.
- Indicadores de desempenho.

### 8. Configurações
- Nome do produtor ou propriedade.
- Configuração da meta mensal.
- Armazenamento local dos dados.
- Opção para apagar movimentações.

## Design e interface

A interface do AgroLucro utiliza uma identidade visual inspirada no ambiente rural, com predominância de tons de verde, branco e cinza.

O sistema foi planejado para apresentar:

- Interface moderna e organizada.
- Navegação por menu lateral.
- Cartões com indicadores financeiros.
- Formulários simples.
- Tabelas para consulta de dados.
- Gráficos de acompanhamento.
- Layout responsivo.
